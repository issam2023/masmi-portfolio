The models are evaluated using Accuracy, Precision, Recall, F1-score and ROC-AUC. The best two models are selected for interactive prediction through Streamlit.

CUSTOMER CHURN • MACHINE LEARNING

Customer Churn Predictor

An end-to-end machine learning project that predicts telecom customer churn using 7,032 customer records and an interactive Streamlit application.

Three classification models are compared using Accuracy, Precision, Recall, F1-score and ROC-AUC. Gradient Boosting achieved the best overall ROC-AUC of 0.841.
