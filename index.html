UNSUPERVISED LEARNING • DATA SCIENCE

Interactive K-Means + PCA Explorer

An interactive unsupervised machine-learning project using the real scikit-learn Wine dataset with 178 samples and 13 numerical features.

K-Means was tested from K=2 to K=10. The best clustering result was K=3 with a silhouette score of 0.2849. PCA is used to reduce dimensionality and visualize the discovered clusters in both 2D and rotatable 3D space.
